# OMPHALOS Logo Asset Package

版本：红金款 · 美漫3渲2 · 透明背景（RGBA PNG）

## 目录
- Source/：透明背景母版，1254×1254，非矢量
- PNG/：29 种正方形 PNG，16～4096 像素，保留透明通道
- Web/：favicon、Apple Touch Icon、Android/PWA 常用尺寸及 Web Manifest
- Windows/：多分辨率 Windows ICO（16、24、32、48、64、128、256）

## 使用建议
- 页面及文档：推荐 PNG/OMPHALOS_512x512.png 或 1024x1024.png
- 网页：Web/favicon.ico 和 Web/apple-touch-icon.png
- Windows 快捷方式：Windows/OMPHALOS.ico
- 高清素材：Source/OMPHALOS_red_gold_master_1254.png

## 技术说明
- 源图像实际为1254×1254；1536、2048、4096尺寸通过高质量插值放大，并非更高细节的原生绘制。
- PNG具备真正的alpha透明通道，但不含可分离编辑的矢量图层。
- 完整字标复杂，16～32尺寸缩小时可能难以辨认；如需小图标可另做仅徽章图标。
